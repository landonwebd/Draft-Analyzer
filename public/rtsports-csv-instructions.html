Download Your RTSports Draft Results

After completing an RTSports draft, download its results as a CSV file so you can import the draft into Draft Analyzer.

  1. Open the completed draft on RTSports.
  2. Select the orange Draft Settings gear near the top-right corner.
  3. Under Export Draft, select Download as CSV.
  4. Return to Draft Analyzer and select the downloaded CSV file.
