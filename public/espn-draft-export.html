ESPN Draft Export

Install the exporter, then use it from a completed ESPN draft's full pick history.

🏈 Export ESPN Draft

  1. Drag the Export ESPN Draft button above to your browser's bookmarks bar.
  2. Open a completed ESPN draft and select the Pick History tab.
  3. Set the round menu to All Rounds.
  4. Click the Export ESPN Draft bookmark in your bookmarks bar.

The exporter detects league size from the fantasy-team names on the page and creates a stable filename based on the draft contents.

Compatibility note: This exporter reads ESPN's draft-results page and may need to be updated if ESPN changes its page layout.
