Import Your FantasyPros Mock Draft

After completing a Draft Wizard mock draft, create its share link and paste that link into Draft Analyzer.

  1. Open your completed mock draft and select the Draft Board tab.
  2. Select Share Draft Board near the top-right corner.
  3. Open the shared draft board and copy its full URL from your browser's address bar.
  4. Return to Draft Analyzer, paste the URL into the FantasyPros import field, and select Import draft.

Experimental: This importer uses FantasyPros' public share link and may stop working if FantasyPros changes its draft-board format.
