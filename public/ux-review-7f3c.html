Draft Analyzer UX Review

Thank you for testing Draft Analyzer. Please approach the app as someone with no fantasy-football knowledge. The goal is to find unclear language, hidden actions, unexpected behavior, and places where the interface assumes too much.

Testing note: Draft Analyzer stores drafts in browser storage. For an isolated test, use a private browsing window. Knowing this page's URL grants access to it; the page is unlinked and excluded from search indexing, but it is not password-protected.

Suggested test

  1. Without importing anything, explore the home page and describe what you believe the app does.
  2. Import both CSV samples at the same time.
  3. Choose UX Tester Team and save each pending draft.
  4. Import the working FantasyPros URL and save that draft.
  5. Try importing the same FantasyPros URL again.
  6. Try the invalid FantasyPros URL.
  7. Open an imported draft and test its position, team, and player-search filters.
  8. Return home and delete one draft.
  9. Open the Personalized Rankings page and test its filters and sortable columns.
  10. Download the rankings CSV.
  11. Refresh the browser and confirm the remaining drafts persist.
  12. Try the experience at a narrow/mobile browser width.
